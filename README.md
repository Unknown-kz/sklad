# Склад — PWA для учёта товаров (Netlify + Firebase)

Приложение для телефона: устанавливается как обычное приложение и работает без интернета.

**Продавец**
- список товаров: название, цена, остаток; поиск
- «Продажа» — остаток уменьшается сам, продажа пишется в отчёт
- «Закуп» — остаток увеличивается, закуп пишется в отчёт
- отчёт за любой день: продажи, закуп, разница, таблица по товарам, список операций (ошибочную можно отменить — остаток вернётся)
- код доступа для магазинов, список магазинов, можно закрыть доступ

**Магазин**
- вводит код продавца → видит его товары, цены и остатки (продажи продавца не видны)
- сколько угодно продавцов, общий поиск по всем

**Push-уведомления**
- магазинам: новый товар, поступление, смена цены
- продавцу: «товар заканчивается» (остаток ≤ 5) и «итоги дня» в 21:00

Сайт и отправка push — **Netlify**, данные — **Firebase** (бесплатный тариф Spark, карта не нужна).

## Как запустить (≈ 25 минут)

### 1. Проект Firebase
1. https://console.firebase.google.com → **Add project** → имя, например `sklad` (Analytics можно выключить).
2. На главной проекта значок **`</>`** (Web) → имя → **Register app**.
3. Значения из `firebaseConfig` вставьте в **`public/firebase-config.js`** вместо `ВСТАВЬТЕ_СЮДА`.

### 2. Вход по email
**Build → Authentication → Get started → Sign-in method → Email/Password → Enable → Save.**

### 3. База данных
1. **Build → Firestore Database → Create database** → любое расположение → режим **production**.
2. Вкладка **Rules** → удалите всё → вставьте содержимое **`firestore.rules`** → **Publish**.

### 4. Ключ для push в браузере
**⚙ Project settings → Cloud Messaging → Web Push certificates → Generate key pair** →
скопируйте ключ в `public/firebase-config.js` → `FIREBASE_VAPID_KEY`.

### 5. Выложить на Netlify
Netlify Drop (перетаскивание папки) **не подходит** — он не запускает серверные функции, push работать не будет. Используйте GitHub:

1. На https://github.com создайте репозиторий (можно **Private**) → **Add file → Upload files** → перетащите **все файлы и папки** проекта → **Commit changes**.
2. На https://app.netlify.com → **Add new project → Import an existing project → GitHub** → выберите репозиторий.
3. Ничего не меняйте (настройки уже в `netlify.toml`) → **Deploy**.
4. Через 1–2 минуты сайт будет по адресу вида `https://ИМЯ.netlify.app` (имя можно поменять: **Project configuration → Change project name**).
5. В Firebase: **Authentication → Settings → Authorized domains → Add domain** → `ИМЯ.netlify.app`.

Регистрация, товары, продажи, отчёты и доступ магазинов уже работают.

### 6. Включить отправку push
1. Firebase: **⚙ Project settings → Service accounts → Generate new private key** → скачается файл `.json`. **Никому его не отправляйте и не загружайте на GitHub.**
2. Netlify: **Project configuration → Environment variables → Add a variable**, добавьте три переменные из этого файла:

   | Переменная | Что вставить из .json |
   |---|---|
   | `FIREBASE_PROJECT_ID` | значение `project_id` |
   | `FIREBASE_CLIENT_EMAIL` | значение `client_email` |
   | `FIREBASE_PRIVATE_KEY` | значение `private_key` целиком, от `-----BEGIN PRIVATE KEY-----` до `-----END PRIVATE KEY-----\n` |

3. **Deploys → Trigger deploy → Deploy project**, чтобы функции получили ключи.
4. В приложении: **Профиль → Включить уведомления**.

**iPhone**: push только в установленном приложении (iOS 16.4+): Safari → «Поделиться» → **«На экран Домой»** → открыть с иконки → Профиль → Включить уведомления.
**Android**: Chrome предложит «Установить приложение» (или кнопка в Профиле).

## Лимиты бесплатного Netlify
Бесплатный план — 300 кредитов в месяц. Больше всего тратит **каждый деплой (15 кредитов)**, то есть примерно 20 обновлений сайта в месяц — не загружайте изменения по одному файлу, лучше пачкой.
Трафик и функции для небольшого магазина почти ничего не стоят. Если кредиты кончатся, сайт встанет на паузу до следующего месяца.

## Как пользоваться
1. Продавец регистрируется как **Продавец**, добавляет товары («+ Товар»).
2. В **Профиле** — код (например `K7M2QX`) → «Поделиться».
3. Магазин регистрируется как **Магазин** → **Продавцы** → вводит код → товары в **Каталоге**.

## Настройки
- Порог «заканчивается» — `LOW_STOCK` в `public/app.js` и `netlify/lib/push.mjs` (сейчас 5).
- Время итогов дня — `schedule` в `netlify/functions/daily-summary.mjs` (время в UTC: `0 16 * * *` = 21:00 в Казахстане).
- Цвет — `--pri` в `public/styles.css` и `theme_color` в `public/manifest.json`.
- После изменений поменяйте `sklad-v1` → `sklad-v2` в `public/sw.js`, чтобы телефоны быстрее обновились.

## Файлы
| Путь | Что это |
|---|---|
| `public/` | само приложение (страница, стили, логика, иконки, офлайн-режим) |
| `public/firebase-config.js` | открытые ключи Firebase (их можно хранить открыто — защита в правилах базы) |
| `netlify/functions/notify.mjs` | рассылка push при изменении товара |
| `netlify/functions/daily-summary.mjs` | «итоги дня» в 21:00 |
| `netlify.toml`, `package.json` | настройки Netlify |
| `firestore.rules` | кто что может видеть и менять в базе |
