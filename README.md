# Склад — PWA для учёта товаров (только Netlify)

Приложение для телефона: устанавливается как обычное приложение, продавать можно даже без интернета.
Всё работает внутри Netlify: сайт, сервер (Netlify Functions), база (Netlify Blobs) и push-уведомления.
**Ничего настраивать не нужно** — ни ключей, ни сторонних сервисов.

**Без регистрации.** На первом экране:
- **Открыть магазин** — ваше имя + название магазина → сразу получаете 6-значный код (например `K7M2QX`)
- **Присоединиться** — ваше имя + код → видите товары, цены и остатки этого магазина

Ролей нет: любой может открыть свой магазин и подключиться к сколько угодно чужим.

**Свой магазин**
- список товаров: название, цена, остаток; поиск
- «Продажа» — остаток уменьшается сам; продать больше, чем есть, нельзя
- «Закуп» — остаток увеличивается
- без интернета продажа и закуп сохраняются в телефоне (⏳) и отправляются сами, когда сеть появится
- отчёт за любой день: продажи, закуп, разница, таблица по товарам, список операций (ошибочную можно отменить — остаток вернётся)
- код можно отправить в WhatsApp, Telegram или любое приложение; ссылка сама подставит код
- видно, кто подключился; любому можно закрыть доступ или сменить код

**Подключённые магазины**
- общий поиск по всем, фильтр по магазину
- видны название, цена и остаток (цены закупа и продажи владельца не видны)

**Push-уведомления**
- подключённым: новый товар, поступление, смена цены
- владельцу: «товар заканчивается» (остаток ≤ 5) и «итоги дня» в 21:00

## Как выложить (≈ 10 минут)

⚠️ Простое перетаскивание папки на Netlify (Netlify Drop) **не подходит**: так не запускается серверная часть, и приложение не сможет сохранять данные. Нужен один из двух способов.

### Способ 1: через GitHub (проще всего)
1. На https://github.com создайте репозиторий (можно **Private**).
2. **Add file → Upload files** → перетащите **всё содержимое** папки `sklad-netlify` (папки `public`, `netlify` и файлы `netlify.toml`, `package.json`, `README.md`) → **Commit changes**.
3. На https://app.netlify.com → **Add new project → Import an existing project → GitHub** → выберите репозиторий → ничего не меняйте → **Deploy**.
4. Через 1–2 минуты откройте адрес вида `https://ИМЯ.netlify.app`. Имя можно поменять: **Project configuration → Change project name**.

Если у вас уже есть проект на Netlify (старая версия), можно подключить к нему репозиторий: **Project configuration → Build & deploy → Link repository**.

### Способ 2: с компьютера через командную строку
Нужен Node.js (https://nodejs.org). В папке `sklad-netlify`:
```bash
npm install
npx netlify-cli login
npx netlify-cli deploy --prod
```

## Первый запуск
1. Откройте сайт → **Открыть магазин** → ваше имя и название магазина.
2. Добавьте товары («+ Товар»).
3. **Профиль** → кнопка **WhatsApp** / **Telegram** / «Ещё…» — отправьте код.
4. Получатель открывает ссылку → вводит своё имя → **Присоединиться**. Товары во вкладке **Магазины**.
5. В **Профиле** нажмите **Включить уведомления**.
6. **Сохраните ключ входа** (Профиль → «Показать»). Он нужен, чтобы войти на новом телефоне или после очистки браузера — без него доступ к магазину не вернуть.

**iPhone**: push только в установленном приложении (iOS 16.4+): Safari → «Поделиться» → **«На экран Домой»** → открыть с иконки → Профиль → Включить уведомления.
**Android**: Chrome предложит «Установить приложение» (или кнопка в Профиле).

## Важно знать
- **Данные хранятся в вашем проекте Netlify.** Если удалить проект на Netlify, удалятся и данные. Обновления сайта (новые деплои) данные не трогают.
- **Лимиты бесплатного Netlify**: 300 кредитов в месяц. Каждый деплой стоит 15 кредитов (≈ 20 обновлений в месяц), поэтому изменения лучше загружать пачкой. Работа приложения для небольшого магазина тратит мало. Если кредиты кончатся, сайт встанет на паузу до следующего месяца — следите за счётчиком в Netlify.
- Данные обновляются каждые 30 секунд, при открытии приложения и при приходе push.
- Вход привязан к телефону. На другом телефоне — «Войти по ключу» (8 символов из Профиля). Потеряли ключ и телефон — магазин не вернуть.

## Настройки
- Порог «заканчивается» — `LOW_STOCK` в `public/app.js` и `netlify/lib/core.mjs` (сейчас 5).
- Время итогов дня — `schedule` в `netlify/functions/daily-summary.mjs` (время в UTC: `0 16 * * *` = 21:00 в Казахстане).
- Цвет — `--pri` в `public/styles.css` и `theme_color` в `public/manifest.json`.
- После изменений поменяйте `sklad-v3` → `sklad-v4` в `public/sw.js`, чтобы телефоны быстрее обновились.

## Файлы
| Путь | Что это |
|---|---|
| `public/` | само приложение: страница, стили, логика, иконки, офлайн-режим, приём push |
| `netlify/functions/api.mjs` | сервер: магазины, коды, товары, продажи, закуп, отчёты, коды доступа, рассылка push |
| `netlify/functions/daily-summary.mjs` | «итоги дня» в 21:00 |
| `netlify/lib/core.mjs` | хранилище, ключи доступа и push (создаются сами при первом запуске) |
| `netlify.toml`, `package.json` | настройки Netlify |
